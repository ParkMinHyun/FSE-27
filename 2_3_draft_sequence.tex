\subsection{Draft Sequence}
\label{sec:draft-background}

The draft sequence comprises the processing stages that produce each capture's initial user-visible draft image.
It was introduced together with the post-processing pipeline, which produces the final image.
When post-processing completes, the final image replaces the draft image if one has been published.

Concurrent execution of draft sequences would require buffering out-of-order results and increase peak compute and memory demand.
The current pipeline therefore uses a single worker to preserve capture order and limit resource demand.

\smallskip\noindent\textbf{Extending the draft sequence.}
The original draft sequence saved an image without additional image processing.
To reduce visual differences between draft and final images, Samsung later added single-frame stages, such as Filter and Watermark.

As post-processing became more resource-intensive, its start was deferred for certain shot modes until the application entered the background to preserve foreground responsiveness.
In these modes, the draft image remains the user-visible result throughout the foreground session, making its visual quality more important.
The draft--final visual gap is particularly pronounced in Super-resolution, Night, High-resolution, and Portrait modes.
Figure~\ref{fig:draft-final-gap} shows an example from Portrait mode.
To reduce this gap, Samsung implemented lightweight multi-frame composition in the draft sequence.
However, the additional processing can cause a Capture Timeout.
Under parallel capture, it can also keep the single draft worker occupied for longer, increasing the waiting time for subsequent captures.
Because of the timeout risk, the feature has not been deployed on any device model.
